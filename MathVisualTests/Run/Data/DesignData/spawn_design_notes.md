# 感染者投放设计说明（节选）

> 本文档节选自策划组内部设计文稿，描述了感染者投放系统的**设计意图**。
> 实际投放结果可能与设计意图存在偏差——发现和分析这些偏差正是本次测试的核心目标。

---

## 1. 基础投放原则

感染者的分布密度由以下因素**叠加**决定：

```
最终密度 = 区域基础密度 × 道路修正系数 × 海拔修正系数 × 据点距离修正系数
```

### 1.1 区域基础密度

| 区域分类 | 基础密度（相对值） | 设计理由 |
|----------|-------------------|---------|
| 荒野（zone 1-7） | 1.0 | 标准参照区域 |
| 功能区（zone 11-23） | 1.5 ~ 2.0 | 废弃设施吸引感染者聚集 |
| 据点核心（zone 33, 35） | 0.1 ~ 0.3 | 幸存者定期清剿 |
| 据点外围（zone 34, 36） | 0.4 ~ 0.6 | 幸存者巡逻但无法彻底清除 |

### 1.2 道路修正系数

距离道路越近，感染者密度**适当降低**（道路区域更开阔、感染者较少聚集）：

| 距最近道路的距离 | 修正系数 |
|----------------|---------|
| >500m（远离道路） | 1.0 |
| 200m ~ 500m | 0.85 |
| 50m ~ 200m | 0.70 |
| <50m（紧邻道路） | 0.55 |

### 1.3 海拔修正系数

| 地形类型 | 海拔范围 | 修正系数 |
|----------|---------|---------|
| 平坦地带 | 0-50 | 1.0 |
| 丘陵地带 | 51-200 | 0.9 |
| 山地 | 201-500 | 0.7 |
| 高山 | >500 | 0.4 |

### 1.4 据点距离修正系数

距离最近据点中心的距离：

| 距离 | 修正系数 |
|------|---------|
| 0 ~ 150m | 0.2 |
| 150m ~ 500m | 0.5 |
| 500m ~ 1000m | 0.8 |
| >1000m | 1.0 |

## 2. 感染者类型分布

### 2.1 全局比例目标

| 类别 | 占比目标 |
|------|---------|
| 普通感染者（M01, M04, M07, M08） | 60-70% |
| 特殊感染者（M02, M03, M05, M06, M09） | 30-40% |

### 2.2 区域差异化

| 区域 | 普通:特殊比例 | 说明 |
|------|-------------|------|
| 荒野 | 7:3 | 以游荡者为主，零星特殊感染者 |
| 功能区 | 5:5 | 废弃建筑内特殊感染者比例更高 |
| 据点周边 | 8:2 | 强力变异体已被幸存者优先清除 |

### 2.3 稀有度控制

| 感染者 | 全局占比目标 | 说明 |
|--------|------------|------|
| M01 游荡者 | 45-55% | 最常见的基础感染者 |
| M04 奔跑者 | 5-8% | 初期感染者，速度快 |
| M07/M08 腐蚀者 | 各 1-2% | 特殊攻击型 |
| M02 嚎叫者 | 10-15% | 召唤型，分布于开阔区域 |
| M03 嚎叫者亚种 | 10-13% | 亚种，分布于密林 |
| M05 猎手 | 1-3% | 精英，伏击型 |
| M06 膨胀体 | 1-2% | 精英，封闭空间多见 |
| M09 巨型变异体 | <1% | Boss 级，仅在高威胁区域 |

## 3. 已知的投放系统局限性

> 以下是策划组已知但尚未修复的问题方向，供分析参考。

1. **边界效应**：区域交界处的密度计算可能不够平滑
2. **高度感知不足**：PCG 系统对海拔的感知精度有限
3. **道路数据精度**：道路网络以可视化图片形式提供，精确程度有限
4. **据点影响范围**：据点的"安全辐射"半径可能需要调整
