# 新手生存经济循环评估 — 技术策划笔试题

## 背景设定

你是一款末日生存 MMO 游戏的技术策划。游戏拥有一个程序化生成（PCG）的大世界废土地图，玩家需要在资源匮乏的废土中生存、采集、战斗和成长。

我们提供了一段 **8km × 8km** 区域的完整经济数据：地图、怪物分布、POI（兴趣点）位置、战斗消耗数据、掉落表、制作配方和装备体系。

一个新手玩家从据点出发，携带 Tier 1 装备和少量初始物资，需要通过**野外采集**和**POI 探索**获取材料，制作更好的装备，逐步成长。

**你的任务是评估这套经济体系是否能支撑健康的新手成长体验，找出经济瓶颈，并提出改进方案。**

## 关键概念速查

### 出征循环

玩家的基本游戏循环：

```
据点出发 → 沿途野外采集 → 进入 POI 战斗 → 携带战利品返回据点 → 制作/修理 → 下次出征
```

每次出征有**收入**（怪物掉落 + 野外采集 + POI 宝箱）和**支出**（弹药 + 医疗品 + 装备耐久修理），两者之差为**净收益**。

### 装备成长路径

```
Tier 1（初始）→ Tier 2（第一次升级）→ Tier 3（核心战力）→ Tier 4（长期目标）
```

每级装备需要从 `crafting_recipes.csv` 查看所需材料。材料来源可追溯到 `loot_table.csv`（掉落）和 `wilderness_resources.csv`（采集）。

### 如何使用战斗结果表

`combat_results.csv` 提供了每种怪物在每档装备下的平均战斗消耗。配合 `poi_list.csv` 中的敌人组成，可以计算一次 POI 探索的总消耗。

## 你的任务

### 阶段一：建立经济模型（Day 1）

构建一个可计算的**经济模型**，回答以下问题：

1. 在每个装备 Tier 下，一次标准出征循环的**收入、支出、净收益**分别是多少？
2. 从 Tier 1 升级到 Tier 2 需要多少次出征循环？Tier 2 → Tier 3 呢？
3. 定义衡量经济健康度的**指标体系**（如：净收益率、时间收益率、死亡风险调整收益……）

> 提示：注意区分"在据点附近打 Tier 1 POI"和"远征去打 Tier 3 POI"的不同经济特征。

### 阶段二：诊断问题（Day 2）

用你的经济模型分析数据，找出以下类型的问题：

1. **死亡螺旋**：是否存在某个阶段，玩家的战损 > 收益，导致越打越穷？
2. **资源瓶颈**：是否存在某种关键材料获取极度困难，卡住整个成长链？
3. **投入产出失衡**：高级弹药/装备的性价比是否真的优于低级？
4. **空间经济**：POI 距据点的距离成本是否被合理定价？

### 阶段三：设计改进方案（Day 3）

针对发现的问题，提出**可量化的改进方案**：

1. 需要调整哪些参数？调整到什么值？
2. 用你的模型验证调整后的效果
3. （加分）是否存在系统性的设计改进（如增加新机制），而非仅调参数？
