# 感染者分布评估与优化 — 技术策划笔试题

## 背景设定

你是一款末日生存 MMO 游戏的技术策划。游戏拥有一个程序化生成（PCG）的大世界废土地图。

我们从世界中截取了一段 **8km × 8km** 的区域供你分析。该区域的地图数据以 **2000 × 2000 像素**的图片形式提供（**1 像素 = 4 米**），同时提供了区域内感染者（怪物）的精确世界坐标。

地图上分布着 9 种感染者，分为 **普通感染者** 和 **特殊感染者** 两大类。区域内存在道路基础设施和 16 个幸存者据点。

**你的任务是评估这份怪物分布的合理性，并提出改进方案。**

## 坐标体系

所有数据使用统一的坐标系：

- **原点 (0, 0)** 位于图片左上角
- **world_x**（米）：向右增大，范围 0 ~ 8000
- **world_y**（米）：向下增大，范围 0 ~ 8000
- **图片像素 ↔ 世界坐标**：`pixel = world_coord / 4`，`world_coord = pixel × 4`

例如：感染者坐标 (3200.0, 5600.0) 对应图片像素 (800, 1400)。

## 你的任务

### 阶段一：建立评价体系（Day 1）

基于提供的数据，建立一套评估"感染者分布合理性"的**量化评价体系**。

你需要回答：
1. **哪些维度**应该被纳入评价？（例如：密度梯度、类型多样性、与地形的关联性……）
2. 每个维度的**合理区间或期望值**是什么？依据是什么？
3. 如何将多个维度的评价**整合为一个可比较的综合评分**？

> 提示：好的评价体系应当能解释"为什么这里的怪物分布是合理/不合理的"。它应基于对数据的实际分析，而非凭空臆测。

### 阶段二：发现问题（Day 2）

用你在阶段一建立的评价体系，分析数据，找出感染者分布中**不合理的具体问题**。

你需要：
1. 用数据和可视化证据支撑每个问题
2. 对问题进行**分类和优先级排序**
3. 分析每个问题的**可能成因**

### 阶段三：设计改进算法（Day 3）

针对阶段二发现的问题，设计一个**能自动优化感染者分布的算法**。

你需要：
1. 描述算法的**输入、输出和核心逻辑**
2. 用伪代码或实际代码实现关键部分
3. 说明算法如何确保**优化后的分布满足你的评价体系**
4. （加分）对优化前后的数据进行对比分析
